Política de privacidad

Información sobre el tratamiento de datos en este sitio estático

1. Alcance

Esta política describe la página informativa de FixCore, un proyecto académico en desarrollo. No describe un servicio comercial de producción.

2. Información solicitada

La versión actual del sitio no contiene formularios de registro, pago o contacto y no solicita información personal directamente a través de ellos.

3. Almacenamiento local

El selector de idioma usa sessionStorage para conservar temporalmente la posición de desplazamiento al cambiar de idioma. No se utiliza para identificarte ni elaborar perfiles.

4. Servicios de terceros

El sitio carga tipografías mediante Google Fonts y puede alojarse en GitHub Pages. Estos proveedores podrían procesar datos técnicos de conexión, como direcciones IP y registros de acceso, conforme a sus propias políticas.

5. Enlaces externos

Al abrir un enlace a GitHub u otro sitio, estarás sujeto a la política de privacidad del proveedor externo.

6. Cambios y consultas

Esta información puede actualizarse conforme evolucione el proyecto. Puedes consultar los repositorios públicos de TechMakers en https://github.com/TechMakers-upc.
