Privacy Policy

How information is handled on this static website

1. Scope

This policy describes the FixCore informational website, an academic project in development. It does not describe a production commercial service.

2. Information requested

The current site has no account registration, payment, or contact forms and does not directly request personal information through such forms.

3. Local storage

The language switch uses sessionStorage to temporarily preserve the scroll position when you change languages. It is not intended to identify or profile visitors.

4. Third-party providers

The site loads fonts from Google Fonts and may be hosted on GitHub Pages. Those providers may process technical connection information, including IP addresses and access logs, under their own policies.

5. External links

If you follow a link to GitHub or another website, that provider’s privacy policy applies.

6. Changes and questions

This notice may change as the project evolves. You can browse TechMakers public repositories at https://github.com/TechMakers-upc.
