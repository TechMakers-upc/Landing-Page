Preguntas Frecuentes

¿Tienes preguntas sobre FixCore?

Respuestas sobre la propuesta y sus funcionalidades previstas.

No está previsto que se requieran sensores IoT ni hardware especializado. FixCore se plantea como una aplicación web accesible desde computadoras y dispositivos móviles.

La propuesta de precios contempla licencias por técnico activo. Los operarios dedicados únicamente a reportar fallas no se contabilizarían como técnicos de pago. Las condiciones definitivas aún deben validarse.

La propuesta busca facilitar el uso desde dispositivos móviles con pasos sencillos para reportar fallas. La facilidad de uso se evaluará con pruebas y retroalimentación de usuarios.

La integración mediante API REST y webhooks forma parte de las capacidades previstas. Su disponibilidad y compatibilidad con ERP se confirmarán durante el desarrollo.
